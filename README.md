## О проекте

Проект содержит функции для вычисления площади и периметра/длины окружности двух геометрических фигур:

| Фигура | Функция | Результат |
|---|---|---|
| Круг | `circle.area(radius)` | Площадь круга |
| Круг | `circle.circumference(radius)` | Длина окружности |
| Квадрат | `square.area(side)` | Площадь квадрата |
| Квадрат | `square.perimeter(side)` | Периметр квадрата |

Для проверки входных данных используется общий модуль `geometry_validation.py`.

## Возможности

- Вычисление площади круга и квадрата.
- Вычисление длины окружности и периметра квадрата.
- Проверка допустимости входных данных.
- Обработка отрицательных, бесконечных и неопределённых значений.
- Проверка ошибочных типов данных.
- Автоматические unit-тесты на стандартном модуле `unittest`.
- Автоматический запуск тестов при push и pull request через GitHub Actions.

## Требования

- Python 3.10 или новее.
- Дополнительные библиотеки для запуска программы и тестов не нужны.
- `unittest` входит в стандартную библиотеку Python.

## Быстрый старт

После публикации репозитория его можно клонировать по URL, указанному на странице GitHub.

Пример использования:

```python
from circle import area, circumference
from square import area as square_area, perimeter

print(area(3))             # 28.274333882308138
print(circumference(3))    # 18.84955592153876
print(square_area(4))      # 16
print(perimeter(4))        # 16
```

## Правила проверки входных данных

Размер фигуры должен быть числом типа `int` или `float`, не являющимся `bool`.

| Входное значение | Поведение |
|---|---|
| Ноль или положительное конечное число | Вычисление результата |
| Отрицательное число | `ValueError` |
| `NaN`, `inf`, `-inf` | `ValueError` |
| Строка, `None`, `bool`, комплексное число, список, кортеж и другие неподдерживаемые типы | `TypeError` |

## Запуск тестов

Из корневой папки проекта выполните:

```bash
python -m unittest discover -s tests -v
```

Либо запустите тестовый файл напрямую:

```bash
python -m unittest tests.test_geometry -v
```

Набор содержит **116 отдельных unit-тестов**. Они проверяют корректные результаты вычислений, граничные значения и обработку некорректных входных данных.

## Автоматическая проверка на GitHub

Workflow находится в `.github/workflows/tests.yml`. GitHub Actions запускает unit-тесты при каждом push и pull request на версиях Python 3.10, 3.11, 3.12 и 3.13.
